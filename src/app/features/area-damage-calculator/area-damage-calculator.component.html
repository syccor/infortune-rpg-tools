Rappel rapide

Le jet d’attaque de zone est lancé une seule fois. Le nombre de cibles touchées est déterminé avec le groupe le plus nombreux.

Pour chaque groupe, les dégâts sont : jet d’attaque × nombre de cibles effectivement touchées.

Le nombre de cibles touchées ne peut jamais dépasser le nombre de personnages présents dans le groupe concerné.
